# Mohammad- portfolio

You are a senior Product Designer, Senior UI/UX Designer, Senior Frontend Engineer, and Software Architect.

Your task is to build a premium personal brand platform for Mohammad Haroon.

This is NOT a simple portfolio website.

This project should feel like a modern SaaS product that happens to showcase a person's work.

The website has four primary goals:

1. Get hired by recruiters.

2. Attract freelance clients.

3. Build a strong personal brand.

4. Showcase projects, products, services and future ideas.

General Design Direction:

• Modern

• Minimal

• Premium

• Elegant

• Clean

• Spacious

• Apple-level attention to detail

• Linear inspired interactions

• Framer quality animations

• Vercel quality layouts

Avoid:

• Generic portfolio templates

• Heavy gradients

• Cheap animations

• Large colorful icons

• Dashboard style layouts

• Old-fashioned cards

Color Palette:

Primary:

#2563EB

Accent:

#7C3AED

Background:

White (#FFFFFF)

Dark:

#09090B

Cards:

#F8FAFC

Typography:

Use Inter.

Spacing should be generous.

Rounded corners should be subtle.

Shadows should be minimal.

The website must support:

• Light Mode

• Dark Mode

• Responsive Design

• RTL Ready

• LTR Ready

• Accessibility (WCAG)

• SEO Ready

The project structure should be scalable for years.

Create the entire project architecture first.

Do NOT generate pages yet.

Instead create:

• Folder Structure

• Routing Structure

• Component Architecture

• Feature Modules

• Data Models

• Design System Foundation

Wait after finishing.
